# SavePiggy 手机原型

Windows 开发，通过 Expo Go 在 iPhone 上预览。此版本验证记账交互，不读取微信、支付宝或 Apple Pay 的真实交易，不发送后台付款通知。

## 电脑浏览器预览

日常调整界面和记账逻辑时可直接在电脑上预览，无需每次扫码，也无需 Expo 登录。

```powershell
cd F:\SavePiggy\mobile
npm run web
```

浏览器通常会自动打开；没有打开时访问终端显示的本地网址。也可以在已经运行 `npm start` 的终端按 `w` 打开网页版。保持终端开启，修改代码后页面会自动更新。

浏览器支持模拟付款、分类保存、账单编辑删除与汇总。确认框使用浏览器的确定和取消按钮。网页账单只保存在当前浏览器，与 iPhone 数据不互通。清除网站数据、使用无痕模式或更换访问地址可能无法保留记录。

浏览器开发者工具的设备模式可用于检查窄屏布局，但不等同于 iPhone 真机。系统通知、快捷指令、锁屏与后台运行等能力后续仍须手机验证。

## iPhone 启动

在 PowerShell 中执行：

```powershell
cd F:\SavePiggy\mobile
npm install
npx expo login
npm start
```

电脑与手机连接同一个 Wi-Fi。手机 Expo Go 登录与电脑相同的 Expo 账号，使用 iPhone 相机扫描终端二维码并在 Expo Go 中打开。服务运行期间请保持终端开启。

若局域网无法连接，先检查 Windows 是否允许 Node.js 通过专用网络防火墙。不要关闭整个防火墙。也可尝试 `npx expo start --tunnel`，按提示安装隧道依赖；此方式需要网络服务可用。

模板使用 Expo SDK 58。请更新 Expo Go；如提示 SDK 不兼容，记录 Expo Go 支持的 SDK 版本，再调整依赖，不要单独修改 React Native 版本。

## 第一次体验

首页固定展示本月累计支出、账单笔数、单笔最高支出及分类分布。点击紫色汇总卡片进入 `/expenses` 支出明细页，在那里切换月度或年度账单；点击年月可打开选择器，按年份选择月份或查看全年。左右箭头切换相邻期间，“回到本月”返回当前月份。金额、笔数和按日期分组的账单同步筛选，仅包含已保存记录。支出日期按当前设备本地日历归属；记账和编辑页面可填写 `YYYY-MM-DD` 补记历史账单。浏览器与手机各自存储数据，不能用两个设备的数据互相验证汇总。

1. 首页点击“模拟付款 ¥28”，选择“去分类”。
2. 确认金额已填入 28.00，选择“餐饮”，点击“保存账单”。
3. 在账单列表查看记录，回首页确认本月汇总为 28.00。
4. 再模拟一笔，选择“稍后处理”：待记账数量增加，总额仍为 28.00。
5. 从待记账中打开记录，分类保存，总额变为 56.00。
6. 编辑一笔金额，再删除一笔，检查总额随之变化。
7. 重新加载项目，确认已保存账单和待记账记录仍然存在。

每笔模拟数据都标注来源。已保存模拟账单会计入汇总，可逐笔删除。手动记账取消后不会创建记录，模拟付款取消分类后仍保留待记账记录。

## 验证命令

```powershell
npm run typecheck
npm test
npm run lint
npx expo export --platform ios
npx expo export --platform web
```

自动检查覆盖金额精度、月度统计和存储数据校验。iOS JavaScript 打包通过不代表真机交互已验证，仍须执行上述手机体验步骤。

## 当前边界

- 提醒是应用内模拟弹窗，不是系统后台支付通知。
- 仅实现人民币支出，不含真实支付接入、退款、转账、导出恢复、加密和云备份。
- 数据使用 AsyncStorage 保存在设备中，未加密；请使用测试数据，卸载、清理 Expo Go 数据或更换项目运行环境可能无法保留记录。
- 若读取失败，暂停写入并提示重试，避免损坏的数据被空列表覆盖。
- 当前是开发预览，不是已上架的独立安装包。自定义原生集成和正式分发后续使用开发构建及云端构建验证。
- 2026 年 10 月 26 日的依赖审计报告包含 5 项 high 告警，涉及 Expo CLI 依赖链中的 node-forge、zod 及上层包。正式发布前需评估兼容的修复版本；不要执行会把 Expo 降级到旧主版本的 `npm audit fix --force`。
